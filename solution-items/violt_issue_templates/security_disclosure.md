# 🔐 Responsible Security Disclosure

Thank you for helping keep Violt users secure.

**DO NOT** file public issues for security vulnerabilities.

Please report all security issues privately via GitHub's [Security Advisory feature](https://github.com/violt-core) or by emailing **security@violt.io**.

We request:
- At least **90 days embargo** before public disclosure
- Clear reproduction steps
- CVSS v3.1 vector (if known)

We aim to respond within **7 business days**.

Your efforts are valued and will be acknowledged if confirmed.
